TPV Restaurante

En desarrollo

Mi proyecto final del ciclo. Un punto de venta con un servidor central y una sola app con dos modos: caja en el PC o la tablet, y comandero en el móvil de los camareros.

El servidor expone una API REST y guarda mesas, comandas, cobros y turnos de caja en PostgreSQL. El dinero se guarda en céntimos para no arrastrar errores de redondeo. Las pruebas levantan una base de datos real con Testcontainers y se ejecutan en GitHub Actions.

Robot ASTI Robotics Challenge

Final 2026 · Burgos

Programé un robot Osoyoo M2 con ruedas mecanum, con un programa para cada prueba:

  • Mini sumo. Echar al rival del ring sin salirse. Cinco sensores de línea vigilan el borde y el ultrasonidos busca al rival. Hay una segunda versión con el sensor sobre un servo que barre como un radar.
  • Siguelíneas. Sigue una línea negra con curvas suaves y, si la pierde, gira hacia el último lado donde la vio.
  • Figuras. Traza un cuadrado, un rectángulo y un triángulo midiendo distancias y giros por tiempo, porque el robot no tiene encoders.
